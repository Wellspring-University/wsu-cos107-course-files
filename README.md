# WSU-COS 107: The Computing & Hardware Laboratory (course files)

Faculty of Computing, Wellspring University · Version 2.0 (October 2026)

These are the files you need for the WSU-COS 107 practicals. Use them with the Practical Manual.

## Getting the files

Download them as a ZIP (green **Code** button, then **Download ZIP**) or, once you have Git installed:

```bash
git clone <this repository's URL>
```

## What is here

| File | Practical | Where the manual uses it |
|---|---|---|
| `Part_A_COS101/P1/P1_test_page.pdf` | P1 | "A one-page test document"; the step "Print and scan one page" |
| `Part_A_COS101/P2/P2_files.zip` | P2 | 20 mixed files with poor names; the step "Build a folder structure" |
| `Part_A_COS101/P3/P3_pack.zip` | P3 | `P3_text.txt`, `P3_table_data.csv`, `P3_ports.png`, `P3_lab.jpg`, `P3_references.txt` |
| `Part_A_COS101/P4/P4_lab_purchases.ods` | P4 | 30 fictional purchases; from the step "Explore the dataset" onward |
| `Part_B_WSU-COS103/P8/P8_upgrade_proposal_sheet.docx` | P8 | The step "Check three upgrades" (one sheet per bench) |
| `Part_B_WSU-COS103/P10/P10_POST_pattern_cards.docx` | P10 | The step "Interpret POST patterns" (print and cut, three per bench) |
| `Part_B_WSU-COS103/P11/READ_ME_Ubuntu_ISO.txt` | P11 | How to obtain and verify the Ubuntu ISO (the ISO itself, about 6 GB, is not included) |
| `Part_B_WSU-COS103/P12/cos107-data.zip` (or `.tar.gz`) | P12 | Sample folder: `file1` to `file20.txt` and `licence.txt` |
| `Part_B_WSU-COS103/P13/READ_ME_faulty-vm.txt` | P13 | The faulty virtual machine (not included: several GB; your instructor provides it) |

Practicals 5, 6, 7 and 9 need no downloaded files. Files you create yourself (`report.txt`, `ascii.txt`, backup archives, screenshots) are not included.

`P3_ports.png` and `P3_lab.jpg` are original illustrations; your instructor may replace them with lab photographs of the same file names. All data is fictional.
